# 📝 Mini Task Tracker – BeFiSc Django Assignment

This is a simple role-based Task Tracker web app built with **Django 5.2**, as part of a technical interview assignment.

---

## 🚀 Features

- 🔐 Authentication (Login/Logout)
- 👥 Role-based access via Django Groups:
  - **Manager**: Can create tasks and assign to employees
  - **Employee**: Can view and update their assigned tasks
- ✅ Task model with title, description, due date, status
- 📋 Dashboard view with task count summary
- 📄 Task list view with filters
- 📊 Task status chart (Chart.js)
- ✅ Permissions enforced in both templates and views

---

## 🧑‍💻 Tech Stack

- Django 5.2
- SQLite (default DB)
- Bootstrap 5 (CDN)
- Chart.js (for pie chart)
